# Project Brief — Horse Riding Club Management System

## What We're Building
A full-stack digital platform to manage all operations of a horse riding club — from public website and trial bookings to student enrollment, attendance, and progress tracking.

## Core Problem
Riding clubs rely on manual registers, phone calls, and spreadsheets. This system digitizes everything.

## Target Users
| User | Access Method |
|------|--------------|
| Visitor | No login — public pages only |
| Student | Mobile number (approved registration) |
| Coach | Mobile number (configured in system) |
| Administrator | Mobile number (configured in system) |

## MVP Scope
- Public landing website (About, Facilities, Horses, Team, Testimonials, Contact)
- Trial ride booking (paid, slot-based, capacity-controlled)
- Student registration (form → pending → admin approval → student created)
- Student Dashboard (attendance, fees, progress, announcements)
- Coach Dashboard (mark attendance, update progress, view batches)
- Administrator Dashboard (full operational control + content management)
- System configuration (trial fees, slots, admin/coach numbers, contact info)

## Out of Scope (v1.0)
Online payments, OTP auth, horse medical records, stable management, merchandise, competitions, AI assistant.

## Success Criteria
All dashboards functional, trial bookings and registrations work end-to-end, content manageable without code changes, runs on Android + iOS + Web.
