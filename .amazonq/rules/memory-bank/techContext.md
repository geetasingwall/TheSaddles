## Key Technology Decisions & Rationale

**No traditional auth in v1.0** — Mobile number lookup determines dashboard. No passwords, no OTP, no JWT. Backend validates number and returns role.

**React (not React Native) for v1.0 web** — Frontend architecture doc specifies React + Vite for the web application. React Native is the future mobile path.

**SQLAlchemy 2.x async-compatible** — Use modern declarative style with type annotations.

**Pydantic V2** — Use `model_config`, `model_validator`, field validators from V2 API. Do not use V1 patterns.

**Alembic for all schema changes** — No manual `ALTER TABLE` in production ever.
